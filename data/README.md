# data/

This folder ships **no real patient data**. Everything here is either bundled
with scikit-learn or generated synthetically.

- Real datasets come bundled with scikit-learn and load with no download
  (`load_breast_cancer`, `load_diabetes`) — see `src/pyhealth_learning/data.py`.
- Practice data is generated on the fly and reproducibly by
  `data.make_synthetic_patients()`, `data.make_synthetic_vitals()` and
  `data.make_synthetic_labs()` — none of it contains real patient information.

## `samples/`

Small, committed CSV previews of the three synthetic datasets so you can open
them in a spreadsheet or load them without importing the package:

| File | Generated by |
| --- | --- |
| `samples/synthetic_patients.csv` | `make_synthetic_patients()` |
| `samples/synthetic_vitals.csv` | `make_synthetic_vitals()` |
| `samples/synthetic_labs.csv` | `make_synthetic_labs()` |

Regenerate full-size copies from the package generators with:

```bash
python data/generate_samples.py
```

If you add your own CSVs here for experiments, never commit protected health
information (PHI).
